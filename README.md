# SmartPark — iOS Parking Application

SmartPark is an iOS application developed using **SwiftUI and MapKit** to help users discover nearby parking locations, compare available options, and navigate to their preferred parking spots.

The project focuses on making the parking experience simpler through location-based search, interactive maps, and an intuitive user interface.

## Features

- **Interactive Maps:** View nearby parking locations using MapKit with map markers and location details.
- **Parking Search & Filters:** Search for parking spots and filter results based on price, distance, and availability.
- **Parking Recommendations:** Discover parking options based on location and user preferences.
- **Navigation:** Get directions to selected parking locations.
- **Favorites:** Save preferred parking locations for quick access.
- **Parking Reports:** Submit and manage parking-related information.
- **Persistent Storage:** Retain saved parking locations, preferences, and submitted reports.

## Technologies Used

- **Swift:** Application programming language
- **SwiftUI:** User interface development
- **MapKit:** Interactive maps and navigation
- **Core Location:** Location-based functionality
- **MVVM Architecture:** Separation of application logic and user interface
- **Xcode:** iOS development environment

## Getting Started

1. Clone the repository:

   `git clone https://github.com/mehulharit/SmartPark.git`

2. Open `SmartPark.xcodeproj` in Xcode.
3. Select an available iOS simulator or compatible device.
4. Build and run the application.
5. Allow location access when prompted to use location-based features.
